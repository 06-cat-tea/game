# 灰烬边境：星陨纪事

原生 JavaScript 与 Canvas 的暗色奇幻 RPG。直接打开 `index.html` 或 `frontier.html` 即可游玩，无需构建、服务器、账号或外部运行时资源。场景分辨率为 1920×1080，桌面与手机统一使用完整 16:9 游戏区域，所有界面都位于游戏画面内部；触控设备竖屏时，游戏区域自动旋转 90°。

线上：https://06-cat-tea.github.io/game/frontier.html

## 操作与功能

- WASD / 方向键移动，靠近目标按 E；鼠标点击 NPC、建筑、室内物件进行交互。
- 右键对象打开对应菜单，空白场景右键访问常用功能；手机长按 450ms 或点击“更多”按钮打开相同菜单。
- 手机左下使用固定移动摇杆，右下为交互、药剂和快捷菜单；电脑也可以用鼠标拖动摇杆，键盘移动优先。打开菜单、对话或功能面板会暂停移动；松手、取消触控、失焦和旋转会清理输入。
- 左上显示小地图、地点、时段和任务提示；右上为背包、任务、队伍、更多，右侧显示最多三位支援同伴，底部显示生命与法力。附近行动、居民、事件及挑战可从“更多”进入。
- 电脑探索时按住 Tab 打开八项快捷轮盘，移出中央选择功能，松开执行；中央松开或 Escape 取消。点击右下菜单按钮后可直接点击项目。对话与面板中 Tab 正常切换焦点。
- 功能面板使用分类、搜索、分页和并排详情，按实际空间减少每页数量；桌面最多 6 项、触控布局最多 4 项。主要操作和翻页按钮固定可见，关闭后返回原场景，场景 Canvas 始终保持挂载。
- 在“设置与存档”中点击“全屏 / 横屏”可进入全屏并尝试锁定横屏；不支持方向锁定时继续使用内部旋转布局。页面不滚动，详细说明可以在游戏内面板中滚动查看。
- 六区域、82 个独立建筑地标、51 个可进入的内室、66 位居民。五个旧区域扩大至 64×48 格；归灯王城为连续的 96×72 格，包含九街区、52 栋建筑、26 处内室和 40 位居民。保留原有 38 张背景与十五条冒险路线，王城采用独立地形、建筑、街具与家具绘制。
- 保留“星钟谜语”及旧居民委托；新增五条两阶段区域支线、10 个一次性选择事件、五名精英、五项区域挑战和“归灯之后”收尾任务。
- 六职业，每职业三分支、每分支五节点，共 90 个技能；四个主动技能配置位、共用技能点和免费确认重配。刺客、牧师与炼金师通过夜岚、艾拉、瑟琳的导师任务解锁。新增十二件职业武器与饰品，接入制作及 +1～+3 强化。
- 六名同伴、三个自动支援位；均衡／突击／守望阵型，输出／保护／资源保留战术。支援技能随主角等级 1／4／7 开放，60 好感解锁羁绊；三组双人协奏使用共享协奏条。
- 一至三名敌人的战斗，目标选择、群攻、护卫、治疗、召唤、精英招式轮换与 Boss 阶段。灼烧、中毒、流血、易伤、破甲、再生、沉默、护盾显示来源及回合；Boss 受硬控制后获得两回合控制免疫。
- 十五张冒险子地图包含调查、补给、选择事件及遭遇；五条三阶段路线调查、六条两阶段个人任务与五项独立高阶挑战。任务详情可定位入口，地点地图可切换区域总览／区域地点，旧路线从“更多 → 冒险路线”进入；支持镜头跟随、缩放与沿入口返回。

## 大场景与归灯王城

晨星镇的王城接待厅新增“前往归灯王城”入口，也可通过世界地图旅行；南门城门署提供返回晨星镇入口。跨区域旅行沿用两个时段的消耗，城市街区之间的地点跳转不消耗时间。公共区域全部开放，无需主线解锁。

九街区为南门驿街、王都大市、蓝瓦匠街、星院书苑、王冠宫庭、河港商埠、灯誓圣区、旧城民巷、翠庭水园。建筑有独立名称、占地、碰撞与交互；水渠不可穿越，三处桥梁连接两岸。52 栋建筑中 26 栋开放内室，其余建筑提供外观、地点介绍或沿街生活内容。没有城市敌群、随机遭遇或调查奖励。

打开“地图 → 区域地点”查看街区或现有地标，点击节点或分页列表即可前往安全落点；内室中使用地点导航会退出内室。地图显示道路、建筑和当前位置，不显示等级、敌群、调查目标或探索奖励。五个旧区域重组已有地点，外围补充道路与自然景观，本次未额外增加旧区域建筑和居民。旧战斗路线改从“更多 → 冒险路线”进入，关联建筑入口和任务定位继续可用。

城市服务包含导览、档案、音乐、补给交易和休息。干粮 20 金币、药剂 28 金币；休息消耗一份旅行补给和一个时段，沿用原生命／法力恢复比例，每日一次。导览、阅读、音乐与地点跳转不增加经验或推进旧任务。

继续使用 v6 存档，扩展位置、城市内室返回点、居民好感与选择均可保存；非法坐标或落入不可通行物中的位置会恢复到安全点。`js/world-regions.js` 统一边界与安全落点，`js/world-terrain.js` 缓存地形和外围景观，`js/city-content.js` 管理城市内容，`js/city-renderer.js` 绘制建筑细节、人物、街具和家具。

`node tests/city-acceptance.cjs [可选 URL]` 检查王城数量、通路、建设预留、全部建筑命中与内室出入、城市服务、对话导入导出、异常存档、和平地图及六种视口。修改清单、截图和结果见 [王城验收说明](王城-验收说明.md)。

## NPC 分支对话

66 位居民各有日常闲聊、区域传闻和个人往事，六位同伴另有深入话题，共 204 个话题。王城 40 位居民新增 120 个身份相关话题。个人往事在好感 20 时开放，深入话题在好感 40 时开放。开场根据时段、主线及委托进度变化；画面突出人物肖像，底部显示当前对白，右侧为“聊聊、委托、服务、赠礼”，右上可告别。各入口按人物能力显示，话题和委托按空间分页，每页最多四项。

点击话题后以约每秒 25 字逐字显示；第一次点击对白或按 Enter / 空格显示完整当前段，第二次推进。长对白按实际宽度和高度分段，电脑最多两行、手机最多三行，无需滚动；“减少动效”启用时整段显示。方向键切换选项，Tab 切换焦点，Escape 返回上一层，在交谈入口时退出。返回话题不会再次领取聊天好感。

自动播放默认关闭，开启后在整段显示完毕时等待 1.5～5 秒再推进；遇到回应选择、菜单切换、失焦或旋转会暂停，不会自动确认回应、委托或赠礼。服务打开独立交易面板；赠礼先显示材料与消耗，再由玩家确认，完成后返回交谈入口。

每日首次交谈好感 +4，每日赠礼好感 +6。每人的往事有一次关系选择，支持回应 +2，中性回应 +0，选项会提前说明。首次回应立即保存并锁定，重读沿已选分支展示；其他话题的选择仅影响当次对白。阅读不会消耗时段或改动任务奖励。完整读完才标记“已读”，中途退出后再次打开从话题首页开始。

对话记录沿用 v6 存档，旧档无需重开；导入、导出和重载均保留已读与选择，当前阅读句数不保存。赠礼会显示具体材料、持有数量与每日状态，地区服务显示实际消耗、收益及可用条件。

## 存档兼容

v6 自动存档沿用 `ashen-frontier-save-v3` 存储键，兼容 v2～v5。迁移前按原版本保留一次备份；旧角色、主线、任务、装备、强化、材料、技能点和已学技能保留，旧战斗迁为单敌人结构。旧同伴羁绊按每级 20 点迁入 0～100 好感。旧档可证明的成就允许领取奖励，未记录的探索项目从未发现开始。新增职业解锁、技能配置、阵型战术、子地图位置与返回栈均可保存恢复。

存档属于当前浏览器与来源：本地文件、localhost 和 GitHub Pages 通常各自保存。换设备或切换来源时，请通过设置导出、导入 JSON 备份。“设置与存档 → 立即保存”直接写入进度；“返回标题”不清空存档，“新游戏”需要确认。轮盘、菜单层级、阅读动画和自动播放为临时状态，无需迁移存档。

## 文件分区

- `frontier.html`、`assets/game.css`、`assets/expansion.css`：页面入口、暗色主题、移动端及战术战斗组件。
- `assets/icons/`：20 枚透明图标，每枚包含 512px 原始资源与 128px UI 资源；基于用户提供的图标集经 imagegen 分离。
- `js/game-data.js`：已有世界、装备、任务、同行者及事件定义。
- `js/building-system.js`、`js/npc-system.js`：建筑、室内空间、物件和居民定义。
- `js/region-content.js`：新区域任务、选择事件、精英与 Boss、专属战利品、收尾任务。
- `js/crafting-system.js`、`js/skill-tree.js`、`js/growth-system.js`：制作、职业、强化、关系、探索与成就。
- `js/scene-system.js`、`js/scene-layouts.js`、`js/scene-controller.js`、`js/expedition-stories.js`：场景定义、逐张背景互动位置与家具碰撞、出入与任务行动、路线事件及敌群。
- `js/class-content.js`、`js/party-system.js`：职业扩展、技能配置与重配、自动支援、阵型、导师及个人任务。
- `js/battle-system.js`、`js/battle-ui.js`：多目标回合、支援和状态结算、固定战斗操作区。
- `js/pixel-world.js`、`js/circle-map.js`：场景绘制、碰撞、目标命中、输入与区域地点地图。
- `js/ui-icons.js`、`js/ui-navigation.js`、`js/interaction-menu.js`：图标映射、分页详情、导航、右键与长按菜单。
- `js/expansion-ui.js`、`js/save-migrations.js`：成长与路线页面、v6 存档迁移。
- `js/game.js`：状态事务及系统协调。
- `js/dialogue-content.js`、`js/dialogue-system.js`：204 个居民话题、分支阅读、条件检查及存档记录。
- `js/game-viewport.js`、`js/game-hud.js`、`assets/hud.css`：16:9 游戏区域、安全区与横屏旋转、统一坐标转换、场景 HUD、输入阻断及八项快捷轮盘。

## 开发与验收

`node tests/dialogue-acceptance.cjs [可选 URL]` 验证全部 204 个话题的两条分支、19／20／39／40 好感门槛、防重复奖励、室内外身份、v2～v6 兼容、存档导入导出、任务反馈、Escape 层级及六种视口中的长对白分段。截图与报告写入 `artifacts/`。

`node tests/viewport-acceptance.cjs [可选 URL]` 使用独立的电脑和真实触控浏览器上下文，覆盖 1920×1080、1280×720、844×390、640×360、390×844、360×640：游戏边界、44px 触控目标、坐标往返、旋转后建筑／人物／地图命中、双指摇杆、松手／取消／失焦／旋转清理、Tab 轮盘八方向与取消、点击模式、Canvas 常驻、战斗操作可见、逐字阅读、自动播放暂停、赠礼确认及交易返回。

可选本地预览：`node tools/serve.cjs 8080`，然后打开 `http://127.0.0.1:8080/frontier.html`。

`node tests/acceptance.cjs` 验证直接打开；`node tests/acceptance.cjs http://127.0.0.1:8080/frontier.html` 验证静态服务。测试只使用独立的无头浏览器存档，结果与截图写入忽略的 `artifacts/`。开发测试使用本机已安装 Playwright 和 Chrome，其他机器可通过 `PLAYWRIGHT_MODULE`、`CHROME_PATH` 指定路径；游戏本身不依赖这些工具。

`tools/build-icons.cjs` 从 512px PNG 重建 128px 资源和检查图；可用 `SHARP_MODULE` 指定开发用 sharp 模块。无需重新生成图标即可运行游戏。

`node tests/expansion-acceptance.cjs [可选 URL]` 检查 38 张背景、51 间内室、15 张子地图、全部互动点步行可达与出口、90 节点、六同伴任务、支援／群攻／召唤／控制免疫、重配退款、v2～v5 备份迁移及桌面和手机五种视口。所有测试均支持直接打开文件、静态服务或线上 URL。

## 内室与路线美术

`assets/expansion/masters/` 保存 38 张 1920×1080 PNG 母版、512px 透明主徽记及六枚职业图标。`scenes/` 保存游戏按当前场景加载的 WebP；图片缓存最多保留四张扩展场景。`icons/` 保存 256px 主徽记、128px 职业图标、简化 SVG 与 32px favicon。新增游戏资源约 16.6 MB，母版不在运行时加载。

所有 45 张新素材通过 imagegen 逐张制作，`assets/expansion/catalog.json` 保存映射及提示词。`node tools/preview-expansion.cjs` 检查母版尺寸、透明通道并生成全部场景联系表；`node tools/expansion-art.cjs <素材ID> <PNG路径>` 导入母版并重建游戏资源。相关图片处理工具仅用于开发，游戏没有外部依赖。

## 地图与人物美术扩展

- 建筑图集的 20 类建筑已分离为透明 PNG，包含 1024px 母版与 512px 场景资源；肖像图集的 20 类人物包含 512px 母版与 256px UI 资源，存于 `assets/world/`。
- 五地分别接入 imagegen 生成的 1920×1080 本地场景背景。建筑与居民仍是可独立交互、按地面深度排序的对象。
- 新增王城、街区、学院、炼金室、马厩、城门、农田、兵营、矿场、旧堡、地牢、云城及港口。15 位新增居民提供训练、炼药、收获、交易、档案、停战和路线服务，并使用统一好感记录。
- `js/world-content.js` 管理扩展地点、居民与服务；`js/world-assets.js` 管理本地图片；`js/world-hit-masks.js` 使用构建时生成的透明命中掩码，兼容直接打开 HTML。
- `assets/world/catalog.json` 包含全部素材映射、来源说明与 imagegen 提示词。`node tools/build-world-assets.cjs` 重建小尺寸资源、命中掩码、透明检查与素材联系表。
- `node tests/world-acceptance.cjs [可选 URL]` 检查 85 张资源、20 类建筑与肖像的实际引用、五区域绘制、全部地标命中、室内居民、服务限制、重载与手机布局。
