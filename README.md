# 灰烬边境：星陨纪事

直接在浏览器打开 `index.html` 即可开始，无需构建步骤、服务器、账号或联网资源。自动存档保存在当前浏览器中；游戏内部画布使用 1920×1080 分辨率并按屏幕尺寸缩放。

## 文件分区

- `frontier.html`：页面结构和本地脚本入口。
- `assets/game.css`：现代化 UI、响应式布局、技能/装备成长卡片。
- `assets/ashen-mark.svg`：本地矢量徽记。
- `js/game.js`：游戏状态协调、战斗、主支线任务、存档迁移和页面交互。
- `js/building-system.js`：五个区域的地标、交互动作与室内空间标识。
- `js/crafting-system.js`：武器、护甲、饰品装备配方与原有消耗品配方。
- `js/skill-tree.js`：游侠、星术师、守誓者职业的三分支技能节点。
- `js/pixel-world.js`：等距 2.5D 场景、地面排序、建筑遮挡/碰撞、点击和 E 键交互、通用空室。
- `js/npc-system.js`：居民资料、所在地点与任务对话。
- `js/circle-map.js`：圆形区域地图绘制和地点导航。

## 操作
