# 灰烬边境：星陨纪事

直接在浏览器打开 `index.html` 即可开始，不需要构建步骤、服务器、账号或联网资源。自动存档保存在当前浏览器中。场景画布为 1920×1080。

## 文件分区

- `frontier.html`：页面结构和本地资源入口。
- `assets/game.css`：游戏 UI、响应式布局和场景叠层。
- `assets/ashen-mark.svg`：本地矢量徽记。
- `js/game.js`：战斗、成长、任务、存档与页面交互。
- `js/npc-system.js`：居民资料与所在地点。
- `js/pixel-world.js`：1920×1080 像素场景、五地建筑、NPC 精灵和移动/交谈。
- `js/circle-map.js`：圆形地图绘制和地点导航。

方向键或 WASD 移动；靠近居民后按 E，或点击居民卡片交谈。与米拉开启「星钟谜语」主线；佩拉、希薇、托伦、艾拉和连舟各自提供相关支线。
