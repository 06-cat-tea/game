# 归灯加载画面

`returning-light.webp` 由 imagegen 生成，原尺寸 1672 × 941；无文字绘画背景，以 WebP quality 88 压缩。标题、目的地、真实加载进度和错误处理均由 HTML/CSS 绘制。

生成描述：手绘奇幻 RPG 的宽屏加载背景。左前景古老石拱与金色提灯，石路穿越深青色森林和河流，通往远方蓝顶王城；黄昏、薄雾、群山，深玉绿与午夜蓝配古金灯光。上方与两侧保留环境细节，下方中央暗而安静，为界面文字留白。无人物、文字、UI 或现代物件。

进入地图前加载整个当前区域的地面、镜头外装饰、建筑、人物、HUD 图标和小地图背景。室内另行加载对应原画。图片解码后重建缓存，等待场景与小地图完成绘制再开放操作。失败可重试，或主动选择原有程序绘制回退；不修改存档格式。
